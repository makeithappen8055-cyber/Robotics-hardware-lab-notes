# ⚡ Electronics - 01: Foundational Electromagnetism & Field Theory

> *"To truly invent new hardware, one must not merely connect components—one must understand the physical laws governing them down to the electron level."*

This module houses the core physical principles behind every circuit, PCB trace, and sensor integration documented in the lab. Instead of treating components like black boxes, this module breaks down electrodynamics into actionable engineering intuition—connecting field theory directly to circuit behavior, noise suppression, and motor control.

## 🔬 Core Learning Methodology

* **Charge Carrier Intuition First:** Model where electrons actually travel before plugging values into equations.
* **Bench-Connected Derivations:** Every concept links directly to real-world hardware behavior—transient spikes, parasitics, and thermal limits.
* **Direct Application:** Physics learned here serves as the theoretical backbone for troubleshooting and designing custom robotics circuits.
